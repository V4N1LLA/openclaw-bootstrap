# 자동 루프 중단 조건

다음 조건 중 하나라도 해당하면 Codex는 자동 작업을 멈춘다.

- secret/token 필요
- `.env` 접근 필요
- git push 필요
- deploy 필요
- force push 필요
- DB 삭제/초기화 필요
- 작업 범위가 허용 파일을 초과
- 테스트 실패 원인이 불명확
- 같은 실패가 2회 반복
- 예상 토큰 등급 `L` 이상
- 사용자 결정이 필요한 제품/아키텍처 판단

중단 시에는 가능한 경우 선택 작업을 `BLOCKED`로 바꾸고, 이유와 사용자가 결정해야 할 다음 한 단계만 짧게 남긴다.
