# 검증 및 인계

목표: 선택된 작업 하나의 검증을 실행하고, `HANDOFF.md`와 `TASK_QUEUE.md`를 갱신한다.

## 규칙

1. 선택 작업의 `검증 명령`만 실행한다.
2. 검증 로그는 핵심 성공/실패 줄만 요약한다.
3. token, secret, password, `.env`, `.env.*`, `secrets/`, `logs/`는 읽거나 출력하지 않는다.
4. 검증 성공 시 `context/TASK_QUEUE.md` 상태를 `DONE`으로 바꾼다.
5. 검증 실패 시 상태를 `BLOCKED`로 바꾸고 실패 원인 후보와 다음 한 단계를 `비고`에 적는다.
6. `context/HANDOFF.md`는 80줄 이하로 갱신한다.
7. `context/HANDOFF.md`에는 현재 목표, 완료한 것, 수정한 파일, 확인한 사실, 실패한 시도, 남은 문제, 다음 한 단계, 검증 상태, 추천 커밋 메시지만 적는다.
8. 출력은 40줄 이하로 한다.
