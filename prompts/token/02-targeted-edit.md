# Targeted Edit

사용자가 제공한 수정 허용 파일 목록 안에서만 작업한다.

## 규칙

- 허용 파일 외 수정 금지.
- 관련 없는 리팩토링 금지.
- 포맷팅만 바뀌는 변경 금지.
- 검증 명령은 필요한 것만 실행.
- 완료 후 전체 코드 출력 금지.
- 보고는 git diff 요약 중심.
- secret, token, password, `.env`를 읽거나 출력하지 않는다.

## 진행 순서

1. 허용 파일 목록 확인.
2. 필요한 파일만 읽기.
3. 최소 수정 적용.
4. 관련 검증 실행.
5. diff 요약 보고.
6. 필요하면 `context/HANDOFF.md` 갱신.
