# Plan Only

sandbox `read-only`에서 실행한다. 파일을 수정하지 말고 계획만 세운다.

## 규칙

- 전체 repo 탐색 금지.
- 처음에는 `AGENTS.md`, `context/current-focus.md`, `context/HANDOFF.md`만 읽는다.
- 추가로 필요한 파일은 최대 5개만 요청한다.
- 구현하지 않는다.
- secret, token, password, `.env`를 읽거나 출력하지 않는다.
- 출력은 30줄 이하로 제한한다.

## 출력 형식

1. 이해한 목표
2. 읽은 최소 컨텍스트
3. 필요한 추가 파일 최대 5개
4. 작업 계획
5. 위험 요소
