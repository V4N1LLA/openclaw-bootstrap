# Handoff Update

작업 종료 시 `context/HANDOFF.md`를 갱신한다.

## 규칙

- `context/HANDOFF.md`는 80줄 이하.
- 완료한 것과 다음 한 단계만 명확히 쓴다.
- 실패한 시도와 확인한 사실을 분리한다.
- 긴 설명 금지.
- 전체 diff, 긴 로그, 파일 전체 내용 금지.
- token, secret, password를 적지 않는다.

## 형식

```md
# HANDOFF

<!-- 80줄 이하로 유지한다. token, secret, password를 적지 않는다. -->

- 현재 목표:
- 완료한 것:
- 수정한 파일:
- 확인한 사실:
- 실패한 시도:
- 남은 문제:
- 다음 한 단계:
- 검증 상태:
- 추천 커밋 메시지:
```
