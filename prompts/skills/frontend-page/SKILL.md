# Frontend Page Skill

React 페이지, 폼, API 연결 작업에 사용한다. 세부 규칙은 필요한 reference만 읽는다.

## 먼저 읽을 references

- Component 변경: `references/component-rules.md`
- Form 변경: `references/form-rules.md`
- API query 변경: `references/api-query-rules.md`
- UI 변경: `references/ui-rules.md`

## 핵심 규칙

- 기존 디자인 시스템과 컴포넌트 패턴을 따른다.
- 페이지는 사용자가 바로 작업을 수행할 수 있게 구성한다.
- API loading, empty, error 상태를 누락하지 않는다.
- 폼은 validation, disabled, submitting 상태를 포함한다.
- 텍스트와 버튼이 모바일에서 넘치지 않게 한다.
- 관련 없는 스타일 정리나 구조 변경을 피한다.
