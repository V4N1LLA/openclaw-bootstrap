# Handoff 규칙

세션이 길어지거나 작업이 끝나면 `context/HANDOFF.md`를 갱신하고 다음 작업은 새 `codex exec` 세션으로 시작한다.

## HANDOFF.md 형식

```md
# HANDOFF

<!-- 80줄 이하로 유지한다. token, secret, password를 적지 않는다. -->

- 현재 목표:
- 완료한 것:
- 수정한 파일:
- 확인한 사실:
- 실패한 시도:
- 남은 문제:
- 다음 한 단계:
- 검증 상태:
- 추천 커밋 메시지:
```

## 작성 규칙

- 80줄 이하로 유지한다.
- 완료한 것과 남은 문제를 분리한다.
- 실패한 시도와 확인한 사실을 섞지 않는다.
- 다음 한 단계는 바로 실행 가능한 문장으로 쓴다.
- 긴 로그, 전체 diff, 파일 전체 내용을 넣지 않는다.
- token, secret, password, 개인 인증 정보를 적지 않는다.
