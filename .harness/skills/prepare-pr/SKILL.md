# prepare-pr

## 목적

PR 설명 초안을 작성한다.

실제 PR 생성은 하지 않는다.

## 포함 항목

- 요약
- 변경 파일 또는 변경 영역
- 검증 결과
- 위험 요소
- 후속 작업

## 절차

1. 작업 ID와 변경 범위를 확인한다.
2. `review-diff` 기준으로 위험 항목을 확인한다.
3. PR 설명 초안을 한국어로 작성한다.
4. 실제 PR 생성 명령은 실행하지 않는다.

## 금지

- 실제 PR 생성 금지
- push 금지
- secret/token/password/API key 원문 출력 금지
