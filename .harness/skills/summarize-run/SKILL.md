# summarize-run

## 목적

Codex/OpenClaw 작업 결과를 Telegram에 짧고 일관되게 요약한다.

## 입력

- 수행한 작업 ID
- 변경 파일
- 검증 명령과 결과
- 남은 TODO
- 추천 커밋 메시지

## 절차

1. 변경 요약을 한두 문장으로 정리한다.
2. 파일 목록은 실제 생성/수정 파일만 적는다.
3. 검증 결과는 실행 명령과 성공/실패만 명확히 적는다.
4. 남은 TODO는 다음 작업 하나를 우선 적는다.
5. 추천 커밋 메시지는 한국어로 작성한다.

## 금지

- secret/token/password/API key 원문 출력 금지
- `.env` 내용 출력 금지
- 불필요한 로그 전문 출력 금지
- 커밋/push 실행 금지
