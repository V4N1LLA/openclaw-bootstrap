# update-task-state

## 목적

`TASKS.md`의 작업 상태를 일관되게 갱신한다.

## 상태

- `TODO`: 아직 시작하지 않음
- `IN_PROGRESS`: 작업 중
- `DONE`: 검증을 통과하고 보고 가능한 상태

## 절차

1. 작업 ID가 `TASKS.md`에 있는지 확인한다.
2. 작업 시작 시 `TODO`를 `IN_PROGRESS`로 바꾼다.
3. Validation 결과를 확인한다.
4. 검증이 성공했을 때만 `DONE`으로 바꾼다.
5. 다음 `TODO` 작업 하나를 `다음 작업`에 반영한다.

## 금지

- 작업 ID가 없는데 임의 추가 금지
- 검증 실패 상태에서 DONE 처리 금지
- 사용자 요청 없이 여러 작업 상태를 한꺼번에 변경 금지
