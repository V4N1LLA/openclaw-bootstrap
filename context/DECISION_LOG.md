- 결정: 자율 루프 하네스 생성 시 TASK-001부터 TASK-004까지는 `DONE`, TASK-005는 `TODO`로 둔다.
- 이유: 이번 변경에서 규칙, 실행 스크립트, 반복 스크립트, 운영 문서를 생성했고, 다음 자동 루프가 자체 리뷰 하나를 고를 수 있어야 한다.
- 영향: `codex-agent-loop.bat` 실행 시 기본 다음 후보는 TASK-005가 된다.
- 되돌리는 방법: `context/TASK_QUEUE.md`에서 필요한 작업 상태를 `TODO`로 되돌린다.

- 날짜: 2026-05-21
- 결정: TASK-005 자체 리뷰 결과, 현재 자율 루프 하네스 규칙과 스크립트 흐름을 유지하고 추가 큐 작업은 만들지 않는다.
- 이유: 운영 문서의 작업 큐 방식, HANDOFF 압축, 중단 조건이 스크립트의 단일 작업 실행 및 최대 5회 반복 경계와 충돌하지 않는다.
- 영향: 다음 자동 루프 실행 시 새 후보 작업은 없으며, 필요하면 사용자가 새 `TODO`를 추가한다.
- 되돌리는 방법: 새 보완 작업이 필요하면 `context/TASK_QUEUE.md`에 허용 범위와 검증 명령을 포함한 `TODO`를 추가한다.

- 날짜: 2026-05-21
- 결정: 자율 루프 운영 메타 파일은 모든 작업에서 갱신 가능하다.
- 이유: `current-focus.md`, `HANDOFF.md`, `TASK_QUEUE.md` 갱신은 루프 실행 자체에 필요하기 때문이다.
- 영향: 실제 산출물은 TASK의 수정 허용 파일을 따르지만, 운영 메타 파일은 예외적으로 허용한다.
- 되돌리는 방법: `prompts/agent-loop/`의 운영 메타 파일 예외 규칙을 제거하고 각 TASK에 메타 파일을 명시한다.
